# Gio's Daily Dispatch

A daily, newspaper-style edition for a fund research analyst: 3 market stories, the technical plumbing underneath each, and a multiple-choice drill. It is read on a Kindle through KOReader.

- `ROUTINE.md`: the instructions the daily scheduled Claude task follows.
- `docs/`: the published site (GitHub Pages). `latest.html` is today's edition.
- `concepts/`: the open-ended concept registry and the question standard.
- `template/`: the reference edition (HTML and CSS) and UI notes.
- `state/history.json`: past editions, for spaced repetition and avoiding repeats.
- `plugin/giodispatch.koplugin/`: the KOReader plugin. Copy it to `koreader/plugins/` on the Kindle.
- `SPEC.md`: the design spec.

Not investment advice. Figures marked illustrative are not market data.
